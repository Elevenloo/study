## 🤖 怎么扔给别的 AI

**最简**：把 `AI_HANDOFF.txt` 全文 + 最新的 `state.json` 一起贴过去，说「接手，按档案回答」。

**完整**：再附上 `DSE2027_考生档案与提升计划.md`（或直接把整个 zip 上传）。

`AI_HANDOFF.txt` 与 `state.json.ai_update_protocol` 都已写明：**AI 每次回答后必须在末尾附加「📌 进度更新」**，列出改动字段、输出**只含改动字段的 merge patch**（按键合并，**不得整档覆盖／重建**）、追加带日期 log、重算 `days_to_each_exam` 与阶段，并提醒你把更新的档存回来。没改动也要明写「本次无进度变动」。

> ⚠️ 若 AI 说「根据计划表里你的成绩是……」但它没读 `state.json`，请提醒它：**以 state.json 为准，正文是 2026-11-16 的初始快照。**
> ⚠️ 若 AI 已更新过 `state.json`，请先在「状态」页**导入**再导出；v1.1 已加防倒灌保护，不会用工具里的旧预估覆盖新档。

## 🎯 今日复习定位器（dse_daily.html · 新增）

直接双击打开 `tools/dse_daily.html`（手机浏览器也行，不用联网、不用安装）。**一打开就是今天**，六个页签：

| 页签 | 做什么 |
|---|---|
| **🎯 今日** | 直接列出段 A／B／C 的**科目 + 具体课题 + 知识点**，附今日在校课表、蓝标补课、周测、日历标记。上方日期选择器可跳到任意一天 |
| **✏️ 50题** | ① 生成指令（自动附带错题检查报告）→ 复制给元宝 → ② 贴回 JSON（校验 50 题、字段、错题变式数量）→ ③ 页内做题、判分，**错题自动入库并标 `rework_pending`** |
| **📝 周测** | 七科**每科每周一次、固定周末**：周六英/化/物/M2，周日数/中/公社；范围自动跟当周课题联动，可记分数 |
| **📅 日历** | 月历 42 格，标记 🔴考试／🟠口试·Gate·周测／🔵校内补课／🟢OLE·周复盘／⛔停课；右上小字是该周 **A/B**；点日期直跳详情 |
| **🔖 错题** | 三分类 + 红标 + 「待回炉／已回炉」；下一次生成 50 题指令会强制带出待回炉错题的**变式题** |
| **⚙️ 资料** | 蓝标补课表、A/B 周一键切换、在校课表摘要、导入／导出全部资料 |

**「每次生成题目都要检查是否有错题」是怎么落实的**：生成指令时先跑 `mistakeCheck()`，列出待回炉错题、红标数、上次 50 题产生的错题，并强制要求 AI 出 ≥ N 道 `source=mistake_rework` 的变式题；贴回 JSON 时会再校验一次数量，不足会红字警告；判分后新错题自动入库，形成闭环。

> ⚠️ 两个工具分工：`dse_daily.html` 管「今天读什么、做题、有没有读懂」；`dse_tracker.html` 管「进度与 state.json 同步」。两者各自用 localStorage，互不覆盖。

## 🛠 工具功能一览（dse_tracker.html）

- **今日**：九项固定作息勾选、净复习分钟、3 行日结、最近 7 日回顾
- **错题**：三分类（概念缺口／审题失误／运算·单位）、筛选、标红（P4 阶段「只留红标」用）
- **成绩**：诊断／测验／Mock／整卷成绩录入；可直接改 7 科当前预估等级
- **计分**：JS4408（权重明确）、JS5102（近似）、JS3741（可调权重）加权分试算，附门槛检查提示
- **状态**：导入／导出 state.json、查看待确认事项、追加 log、一键复制「给 AI 的接手摘要」
- 资料存在浏览器 localStorage，**不会上传**；换设备请导出 state.json 再导入

## ⚠️ 三个必须记住的事实

1. **英文 3 是入场门槛**，不是加分项。JS3741／JS4408／JS5102 都要求 ENG L3；拿 2 就三个 Band A 同时失效。所以段 A 永远先给英文 P3。
2. **四核心六天连考**（4/8 中文 → 4/9 英 P1P2 → 4/10 英 P3 → 4/12 数学 → 4/13 公社，中间只有 4/11 一个空档）。第一轮完整复习必须 **3 月底前收工**，4 月只能维持手感。
3. **英文 P3 在星期六**，是你最弱的一卷。所以每周六 09:15 固定做计时整卷，让生理时钟对齐考试钟。
