📖 使用说明

1. 打开即见「今天」三段科目 + 具体课题；上方日期选择器可定位任意日。
2. 「50 题」页生成指令 → 复制给元宝 → 回覆 JSON 贴回 → 在本页做题、判分、错题自动入库。
3. 「周测」页每科每周一次，固定在周末；范围自动跟当周课题联动。
4. 「日历」显示考试、Gate、周测、补课、停课、OLE、周复盘；点日期直跳详情。
5. 所有资料存浏览器 localStorage，不上传；换设备先导出。
6. 你稍后补的「课程表 / 补课时间」可在「导入」覆盖，不必重做工具。
